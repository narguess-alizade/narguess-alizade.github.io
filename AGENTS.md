# AGENTS.md

al-folio fork configured as Narguess Alizade's personal GitHub Pages site. Most of the repo is upstream theme code, so `README.md`, `INSTALL.md`, `CUSTOMIZE.md`, and `FAQ.md` document the theme in general, not this site. The actual site is driven by `_config.yml` plus the content directories.

## Build & verify

There is no test suite. Verify changes by rendering the site.

```bash
docker compose up          # serve at http://localhost:8080 (prebuilt amirpourmand/al-folio:v0.16.3)
docker compose down        # stop, free port 8080
docker compose up --build  # rebuild after Dockerfile/dependency changes
docker compose -f docker-compose-slim.yml up   # slim image variant
```

CI (`deploy.yml`) runs `JEKYLL_ENV=production bundle exec jekyll build`, so production-only plugin/minifier failures can pass locally by default.

## Formatting (required)

Prettier is enforced by CI (`prettier.yml`) and blocks PRs.

```bash
npx prettier . --write
```

Config: `.prettierrc` (`printWidth: 150`, liquid plugin). `.prettierignore` excludes `_scripts/*`, `assets/css/main.scss`, and generated `_data/citations.yml`.

## Configuration

- `_config.yml` is the primary control surface: feature flags (`enabled:`), navigation, collections. Social links live in `_data/socials.yml`.
- `url`/`baseurl` are already correct for this personal site (`https://narguess-alizade.github.io`, empty `baseurl`) — do not add a baseurl.
- Quote YAML strings containing `:`, `&`, or `#`, or the build fails to parse.

## Layout & generated files

- Content: `_pages/`, `_posts/` (`YYYY-MM-DD-title.md`), `_projects/`, `_news/`, `_teachings/`, `_books/`, `_bibliography/papers.bib`.
- Templates/styles: `_includes/`, `_layouts/`, `_sass/`, `_scripts/`.
- `_data/citations.yml` is generated by `bin/update_scholar_citations.py` via scheduled CI — never hand-edit it.

## Deploy

- Push to `main` triggers `.github/workflows/deploy.yml`, which builds and pushes `_site/` to the `gh-pages` branch.
- Docs-only changes (README, CUSTOMIZE, INSTALL, FAQ) do not trigger a deploy.
- `_site/` is gitignored. `Gemfile.lock` is tracked even though `.gitignore` lists it.
